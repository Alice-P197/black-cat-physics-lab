电荷函数

charge(x, y, q)在 (x, y) 处放置点电荷 q（单位 µC，正负号决定极性）
line(x1, y1, x2, y2, qTotal, n)沿线段均匀放置 n 个电荷，总电量 qTotal
ring(cx, cy, R, qTotal, n)以 (cx, cy) 为圆心、半径 R 的带电圆环，n 个电荷均分总电量
disk(cx, cy, R, qTotal, nRings, nPerRing)均匀带电圆盘（面积加权），nRings 个同心环，每环 nPerRing 个点
parallelPlates(x1, x2, y, d, qTotal, n)平行板电容器：上板 +qTotal，下板 -qTotal，间距 d，每板 n 个点

探测函数

probeLine(x1, y1, x2, y2)设置测量线起止点
probe(x, y)设置场点探测位置

动画函数

showCard()显示画布上的实时数据卡片
hideCard()隐藏数据卡片
probeMoveTo(x, y, duration)从当前位置线性移动到目标点，耗时 duration 毫秒
probePath([[x,y],...], {duration, loop, pingpong})沿点列表路径移动；pingpong=true 表示往返运动
probeCircle(cx, cy, R, duration, loop)以 (cx, cy) 为圆心、半径 R 做圆周运动
probeOscillate(axis, amp, period, phase, loop)沿 'x' 或 'y' 轴做简谐振荡，振幅 amp、周期 period 毫秒
stopAnim()立即停止当前动画

工具函数

range(a, b, step)返回从 a 到 b 的等差数列（含端点）
linspace(a, b, n)返回从 a 到 b 均匀分布的 n 个数
PI · Math.*标准数学常量与函数（sin、cos、pow、sqrt 等）

电荷快捷操作

框选在画布空白处按住鼠标拖动 → 绘制选择框，释放后框内电荷被选中
Delete / Backspace删除当前选中的所有电荷
鼠标右键点击电荷直接删除该电荷（无需先选中）
单击空白移动探测点并清除选中状态
