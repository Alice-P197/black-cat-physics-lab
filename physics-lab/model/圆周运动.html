匀速圆周运动公式

角速度（恒定）
$$\omega = \omega_0$$
线速度
$$v = \omega r = \omega_0 r$$
切向加速度
$$a_t = \frac{dv}{dt} = 0$$
法向加速度（向心）
$$a_n = \frac{v^2}{r} = \omega^2 r$$

非匀速圆周运动公式

角速度与角位移
$$\omega = \omega_0 + \alpha t$$ $$\theta = \omega_0 t + \tfrac{1}{2}\alpha t^2$$
线速度
$$v = \omega r = (\omega_0 + \alpha t)\,r$$
切向加速度
$$a_t = \frac{dv}{dt} = r\alpha$$
法向加速度（向心）
$$a_n = \frac{v^2}{r} = \omega^2 r$$
