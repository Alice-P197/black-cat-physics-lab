公式推导

一、物理模型

设链条总长 $L$、总质量 $M$、线密度 $\lambda = M/L$。 初始时刻，长度为 $x_0$ 的一段悬垂于桌边外，其余部分平铺在光滑桌面上。 取桌面为零势能面，忽略摩擦与弯曲处的能量损失。

关键假设：桌面光滑，整条链条以相同速度运动。 这是经典问题的标准设定，可保证机械能守恒。

二、运动方程

任意时刻，悬垂部分长度为 $x$，其质量为 $\lambda x$，所受重力为 $\lambda x g$。 对整条链条（质量 $M = \lambda L$）应用牛顿第二定律：

$$\lambda x g = M a = \lambda L a \quad\Longrightarrow\quad a = \frac{g}{L}\,x$$

写成二阶微分方程：

$$\ddot{x} = \omega^2 x,\qquad \omega \equiv \sqrt{\frac{g}{L}}$$

三、运动学解

代入初始条件 $x(0) = x_0$、$v(0) = 0$，得

$$x(t) = x_0\cosh(\omega t)$$ $$v(t) = x_0\,\omega\sinh(\omega t)$$ $$a(t) = x_0\,\omega^2\cosh(\omega t) = \frac{g}{L}x(t)$$
物理意义：$\ddot{x} = +\omega^2 x$ 的系数为正， 对应双曲余弦增长；重力持续把链条往外拉，悬垂越长拉力越大， 形成正反馈式的加速过程。

四、重心高度

桌面部分（长 $L-x$）位于 $y=0$；悬垂部分（长 $x$）的质心在桌边下方 $x/2$ 处， 即 $y = -x/2$。故整条链条重心高度为

$$y_c = \frac{(L-x)\cdot 0 + x \cdot \left(-\dfrac{x}{2}\right)}{L} = -\frac{x^2}{2L}$$

重心随悬垂长度增大而单调下降，且以 $x^2$ 规律下降，这正是势能释放的来源。

五、动能与重力势能

动能：

$$E_k = \tfrac{1}{2}Mv^2 = \tfrac{1}{2}M \cdot \frac{g}{L}\left(x^2 - x_0^2\right)$$

重力势能（桌面为零势能面）：

$$E_p = M g y_c = -\frac{Mg}{2L}x^2$$

势能变化量（相对于初始状态）：

$$\Delta E_p = E_p - E_{p0} = -\frac{Mg}{2L}\left(x^2 - x_0^2\right)$$

势能减少量 $|\Delta E_p|$ 与动能 $E_k$ 完全相等：

$$\boxed{\;E_k = -\,\Delta E_p = \frac{Mg}{2L}\left(x^2 - x_0^2\right)\;}$$

六、机械能守恒验证

总机械能 $E = E_k + E_p$ 在运动过程中保持恒定：

$$E = \frac{Mg}{2L}(x^2 - x_0^2) - \frac{Mg}{2L}x^2 = -\frac{Mg}{2L}x_0^2 = \text{const}$$

这与运动学解完全自洽，说明上述模型满足机械能守恒。 下方图表中的“能量守恒对比图”会把 $E_k$ 与 $|\Delta E_p|$ 同时绘出， 两条曲线应完全重合。

七、链条完全离开桌面的时刻

当 $x = L$ 时链条尾端脱离桌面，由 $L = x_0\cosh(\omega t_{\rm end})$ 解得

$$t_{\rm end} = \frac{1}{\omega}\,\operatorname{arccosh}\!\left(\frac{L}{x_0}\right)$$

此时速度、动能、势能释放量分别为

$$v_{\rm end} = \sqrt{\frac{g}{L}\left(L^2 - x_0^2\right)}$$ $$E_{k,\rm end} = \frac{Mg}{2L}\left(L^2 - x_0^2\right)$$ $$|\Delta E_{p,\rm end}| = \frac{Mg}{2L}\left(L^2 - x_0^2\right)$$
