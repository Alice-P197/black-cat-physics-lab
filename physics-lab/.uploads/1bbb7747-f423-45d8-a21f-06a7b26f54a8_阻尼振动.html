阻尼振动

欠阻尼 · 临界阻尼 · 过阻尼 —— 振幅随时间衰减

阻尼状态 欠阻尼 角频率 ω₀ 4.47 rad/s 阻尼振动频率 ω_d 4.45 rad/s 初始能量 10.0 J

阻尼振动方程

$$m\ddot{x} + b\dot{x} + kx = 0$$

引入阻尼比 $\zeta = \dfrac{b}{2\sqrt{km}}$ 与固有角频率 $\omega_0=\sqrt{k/m}$， 方程化为：

$$\ddot{x} + 2\zeta\omega_0\dot{x} + \omega_0^2 x = 0$$

三种阻尼状态

欠阻尼（$\zeta < 1$）：$\quad x = Ae^{-\zeta\omega_0 t}\cos(\omega_d t + \varphi)$ $$\omega_d = \omega_0\sqrt{1-\zeta^2}$$
临界阻尼（$\zeta = 1$）：$\quad x = A(1+\omega_0 t)e^{-\omega_0 t}$
过阻尼（$\zeta > 1$）：$\quad x = A e^{-\zeta\omega_0 t} \left[\cosh(\omega_h t) + \dfrac{\zeta\omega_0}{\omega_h}\sinh(\omega_h t)\right]$ $$\omega_h = \omega_0\sqrt{\zeta^2-1}$$

能量衰减

$$E = \tfrac{1}{2}mv^2 + \tfrac{1}{2}kx^2,\qquad \frac{dE}{dt} = -bv^2 < 0$$
