平抛运动公式

水平方向（匀速）
$$x = v_0 t,\qquad v_x = v_0$$
竖直方向（自由落体）
$$y = h - \tfrac{1}{2}gt^2,\qquad v_y = gt$$
合速度
$$v = \sqrt{v_0^2 + g^2 t^2}$$
落地时间
$$T = \sqrt{\dfrac{2h}{g}}$$

斜抛运动公式

运动方程
$$x = v_0\cos\theta\cdot t$$ $$y = v_0\sin\theta\cdot t - \tfrac{1}{2}gt^2$$
速度分量
$$v_x = v_0\cos\theta$$ $$v_y = v_0\sin\theta - gt$$
最大高度
$$H = \dfrac{v_0^2\sin^2\theta}{2g}$$
射程与飞行时间
$$R = \dfrac{v_0^2\sin 2\theta}{g}$$ $$T = \dfrac{2v_0\sin\theta}{g}$$

竖直上抛运动公式

位移与速度
$$y = v_0 t - \tfrac{1}{2}gt^2$$ $$v = v_0 - gt$$
最大高度
$$H = \dfrac{v_0^2}{2g}$$
上升时间
$$t_{\uparrow} = \dfrac{v_0}{g}$$
总飞行时间
$$T = \dfrac{2v_0}{g}$$
